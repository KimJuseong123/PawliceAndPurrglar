## 3. 공모전 — 확보한 것과 없는 것

### 참가 약관에서 우리에게 걸리는 조항

| 조항 | 내용 |
|---|---|
| **제4조 1항** | 출품 시 **AI 도구의 명칭과 활용 방식을 고지할 의무.** `SUBMIT-004`가 선택이 아니라 **필수**다 |
| **제4조 2항** | 출품작은 **참가자 본인의 순수 창작물**이어야 하며 타인 권리 미침해를 보증 |
| **제4조 3항** | 생성형 AI·오픈소스·**외부 API** 사용 시 **라이선스 및 이용 조건 준수** |
| 제6조 1항 | 저작권·지식재산권은 **원칙적으로 참가자에게 귀속** |
| 제6조 2항 | 수상작은 주최사가 **접수 시작일로부터 1년** 무상 이용 (홍보·발표·사례집·아카이브) |
| 제7조 | 수상 시 **공모전 종료일로부터 4개월** 주최사 우선협상권. 채용 여부와 무관 |
| 제2조 | 만 19세 이상, **팀 최대 3인** |
| 제5조 4항 | 팀 상금은 **팀이 제출한 배분 내역**대로 개별 지급 |
| 제8조 | 표절·무단 도용·허위 기재 시 참가 제한 또는 수상 취소 |

### 확인이 필요한 것

**약관에 제출 규격이 없다.** 제3조 4항이 "주최사가 별도 안내하는 **운영 규정**",
제4조 1항이 "주최사가 정한 **제출 기한 및 형식**"으로 미루고 있다.

그래서 아직 모르는 것:

1. **플랫폼이 WebGL로 괜찮은가** (지금 WebGL 확정으로 진행 중)
2. **영상 길이·형식**
3. **문서 양식**
4. **AI 생성 에셋 취급** — 이게 가장 중요하다

### ⚠️ 4번이 왜 중요한가

제4조 2항이 "**참가자 본인의 순수 창작물**"을 요구한다. 그런데 이 게임은:

- 캐릭터·건물·소품 모델 대부분이 **Tripo AI** 생성물
- BGM이 **Suno** 예정 (현재 로비 트랙 1개는 별도 출처, 라이선스 기록 필요)
- 개발 자체에 AI를 광범위하게 사용

순수 AI 생성물은 한국·미국 모두 **저작권 보호를 받지 못한다**는 것이 현재 판단이다.
사용에는 문제가 없지만 "우리가 저작권을 가진다"고 주장할 수는 없다.
제6조 1항이 저작권을 참가자에게 귀속시키는데, **귀속시킬 저작권이 없는 에셋**이 섞여 있는
상태가 어떻게 해석되는지는 **법률 판단이라 개발 쪽에서 답할 수 없다.**

**운영 규정에 AI 생성 에셋 조항이 있는지 반드시 확인해야 한다.**
그 문서를 구하면 `DOC-004`를 마무리할 수 있다.
