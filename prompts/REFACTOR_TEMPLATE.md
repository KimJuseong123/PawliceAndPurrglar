사전 검증:
1. 현재 동작을 재현한다.
2. 보호할 테스트를 확인하거나 추가한다.
3. 공개 API와 직렬화 필드를 기록한다.

요구사항:
1. 외부 동작을 변경하지 않는다.
2. 씬과 프리팹 참조를 가능한 한 유지한다.
3. 직렬화 필드 이름 변경은 마이그레이션 없이 수행하지 않는다.
4. 새 추상화는 실제 중복이나 결합을 줄여야 한다.
5. 관련 없는 정리 작업을 포함하지 않는다.

완료 조건:
- 기존 테스트가 통과한다.
- 추가한 테스트가 통과한다.
- 공개 동작이 동일하다.
- 컴파일과 Play Mode 오류가 없다.
- 변경 이유와 영향이 문서화된다.

완료 보고:
- 변경 전 문제
- 선택한 구조
- 대안과 선택 이유
- 변경 파일
- 동작 보존 검증
- 남은 위험
