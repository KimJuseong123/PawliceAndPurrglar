# 코드 리뷰 템플릿

```text
현재 변경 사항을 코드 리뷰한다.

먼저 읽을 문서:
- AGENTS.md
- docs/13_CURRENT_STATE.md
- docs/14_DECISION_LOG.md
- docs/03_GAME_RULES.md
- docs/05_TECH_ARCHITECTURE.md
- docs/10_TEST_PLAN.md

검토 기준:
1. 사용자 요청과 확정된 결정에 맞는가
2. 확정 규칙과 가설값을 혼동하지 않았는가
3. Core 규칙과 UI, 애니메이션, 입력이 분리되어 있는가
4. 키보드와 향후 음성이 같은 명령 ID 경로를 사용하는가
5. 중복 판매, 중복 체포, 중복 경기 종료 가능성이 있는가
6. null, 비활성, 파괴된 객체를 처리하는가
7. 씬 재시작 후 정적 상태와 이벤트 구독이 남는가
8. 네트워크 권한을 Core에 직접 결합하지 않았는가
9. 테스트가 실제 요구사항과 실패 조건을 검증하는가
10. 레거시 실험 코드를 무단으로 새 구조에 복사하지 않았는가
11. 불필요한 변경이나 패키지가 포함되었는가
12. Current State, Decision Log, Known Issues 갱신이 필요한가

출력:
- Critical
- High
- Medium
- Low
- 테스트 누락
- 문서 불일치
- 열려 있는 질문
- 최종 판단

각 발견 사항에 파일과 줄을 적고, 영향과 수정 방향을 설명한다.
문제가 없으면 남은 테스트 공백과 위험을 명시한다.
```
