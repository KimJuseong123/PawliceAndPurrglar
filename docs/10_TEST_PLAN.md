## 5. 경기 상태

- `LOBBY -> READY -> PLAYING -> ENDING -> RESULT`
- 새 상태 머신은 `LOBBY`에서 시작
- 허용된 순차 전환만 성공
- 같은 상태로 중복 전환 시 상태 변경 알림 없음
- 건너뛰기, 역방향, 정의되지 않은 상태 거부
- `IsGameplayActive`는 `PLAYING`에서만 참
- 준비 중 이동과 상호작용 제한
- `ENDING` 이후 추가 판매와 체포 불가
- 결과가 한 번만 확정됨
- 재시작 후 타이머와 결과 초기화

## 6. 경찰 승리

### 시간 종료

1. 경기를 시작한다.
2. 도둑이 목표 금액에 도달하지 않는다.
3. 4분이 종료된다.
4. 경찰 승리와 정확한 이유가 표시된다.

### 체포

1. 경찰이 도둑에게 접근한다.
2. 체포 진행도를 완료한다.
3. 경찰 승리가 한 번만 판정된다.
4. 이후 판매 요청이 무시된다.

## 7. 도둑 승리

1. 도둑이 유효한 보물을 획득한다.
2. 너구리 상인 범위에서 판매한다.
3. 누적 금액이 목표에 도달한다.
4. 도둑 승리가 한 번만 표시된다.
5. 이후 체포와 추가 판매가 결과를 바꾸지 않는다.
