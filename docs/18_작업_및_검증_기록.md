# 작업 및 검증 기록

> 2026-07-30 기준 WebGL 음성 명령 MVP, 로컬 플레이테스트 경로, Blender 원본 자산 추가 작업을 정리한 문서입니다.

## 1. 작업 요약

- 기존 숫자키·버튼 명령을 유지하면서 WebGL 브라우저 음성 입력 경로를 추가했다.
- Unity 클라이언트와 같은 저장소의 `server/` Fastify TypeScript 서비스 사이를 연결했다.
- OpenAI 인증 정보는 서버 환경 변수로만 관리하도록 분리했다.
- 브라우저 음성이나 외부 서비스가 실패해도 기존 숫자키·버튼 명령은 계속 사용할 수 있게 했다.
- `ArtSource/Blender/`에 추가된 동물 상호작용물, 경찰·도둑 소품, 표현 아이콘, 효과음을 목록화했다.

## 2. WebGL 음성 명령 경로

```text
WebGL MediaRecorder
  -> Fastify multipart API
  -> 음성 업로드 검증 및 STT
  -> 절대 명령 매칭 / 제한된 Intent 후보 생성
  -> Host 전용 WebSocket
  -> PetCognitionResolver
  -> 기존 CompanionCommandDispatcher
```

- 브라우저 녹음은 최대 5초, 업로드는 최대 5MB로 제한한다.
- 절대 명령은 Intent 모델보다 먼저 매칭한다.
- 서버는 정규화된 텍스트와 제한된 후보만 반환한다.
- NGO Host가 대상 ID, 진영, 거리, 쿨다운, 실행 가능 여부를 최종 검증한다.
- 최종 동물 행동과 무작위 결과는 Host가 결정한다.
- 음성 실패 시 숫자키 `1`~`4`와 버튼 입력을 fallback으로 사용한다.

## 3. 로컬 실행 및 환경 변수

- 저장소 루트의 `play-webgl.bat`가 WebGL 플레이어와 정적 서버를 실행한다.
- WebGL 정적 서버 기본 포트는 `8080`, 선택적 음성 서버 기본 포트는 `3000`이다.
- OpenAI 키 입력 위치는 `server/.env`이다.
- 커밋 대상 예시 파일은 [`server/.env.example`](../server/.env.example)이며, 실제 `.env`와 키는 저장소에 포함하지 않는다.
- 음성 서버는 `OPENAI_API_KEY`, STT 모델, Intent 모델, 제한 시간, 허용 Origin 등을 환경 변수에서 읽는다.

## 4. 추가 Blender 원본 자산

실제 원본 경로는 `Assets/Blender/`가 아니라 `ArtSource/Blender/`이다.

| 그룹 | 추가 수량 | 내용 |
|---|---:|---|
| `cat_interact` | 2 | 초록 잎 파우치, 분홍 털실 공 |
| `dog_interact` | 9 | 파우치, 조형물, 닭, 발자국, 호루라기, 물약병, 깃발, 해골, 테니스공 |
| `police_stuff` | 9 | 경찰 장비·경계·조명 소품 |
| `theif_stuff` | 3 | 골판지 상자, 로우폴리 가방, 나무 상자 |
| `expression_icon` | 4 | 전구, 느낌표, 하트, 나선형 배지 |
| `sound_effects` | 2 | 고양이 울음, 사이렌 |

아이템별 경로와 프로토타입 사용 후보는 `docs/17_게임_아이템_사용처_정리.md`에 기록했다. 자산 추가만으로 가격, 승리 조건, 공격 기능을 확정하지 않는다.

## 5. 테스트 및 정리 기록

- 서버 TypeScript 단위 테스트와 타입 검사를 실행했고 결과를 아래에 기록했다.
- Markdown 및 자산 경로를 정적 확인한다.
- 테스트 후 생성된 `server/dist/`는 삭제했다.
- `server/audio-debug/`와 실제 `server/.env`는 저장소에 존재하지 않는다.
- Unity `Library/`, `Temp/`, `Logs/`, `obj/`와 `server/node_modules/`는 로컬 생성 영역으로 유지하고 커밋하지 않는다.
