# UI/UX 사양

## 1. 목표

- 플레이어가 자신의 역할과 현재 목표를 즉시 이해한다.
- 4분 타이머, 보물, 체포, 동물 명령 상태를 한눈에 읽는다.
- 프로토타입의 숫자키 입력과 향후 음성 입력이 같은 UI 상태를 사용한다.
- 귀엽고 활기찬 분위기를 유지하되 추격 화면을 가리지 않는다.

## 2. 화면 구성

### 공통 HUD

- 남은 시간
- 역할 아이콘과 색상
- 상대의 목표 진행 상태
- 현재 상호작용 안내
- 일시적인 사건 알림
- 명령 슬롯 `1`~`4`

### 경찰 HUD

- 도둑의 누적 판매 금액 또는 목표 진행도
- 강아지 현재 상태
- 강아지 명령 4개와 쿨타임
- 도난 발생 알림
- 추적 흔적의 유효 시간
- 체포 진행도

### 도둑 HUD

- 현재 판매 금액과 목표 금액
- 보유 보물과 가치
- 보물 소지 이동 페널티
- 고양이 현재 상태
- 고양이 명령 4개와 쿨타임
- 경찰 접근 경고
- 까마귀 상인 판매 가능 상태

## 3. HUD 배치 원칙

- 타이머는 화면 상단 중앙에 둔다.
- 자신의 정보는 화면 하단 또는 좌우 한쪽에 일관되게 둔다.
- 명령 슬롯은 숫자키와 명령 아이콘이 함께 보이게 한다.
- 화면 중앙은 추격과 투척 궤적을 위해 비워 둔다.
- 미니맵은 MVP 필수 기능이 아니다.
- 텍스트보다 아이콘, 색상, 짧은 상태 문구를 우선한다.
- 색상만으로 진영과 상태를 구분하지 않는다.

## 4. 명령 슬롯

각 슬롯은 다음 상태를 표현한다.

- `READY`: 사용 가능
- `SELECTING_TARGET`: 대상 또는 위치 선택 중
- `ACCEPTED`: 명령 접수
- `EXECUTING`: 실행 중
- `COOLDOWN`: 쿨타임
- `REJECTED`: 실행 거부
- `NO_TARGET`: 유효 대상 없음
- `DISABLED`: 동물 행동 불능 또는 경기 종료

필수 표시:

- 숫자키
- 명령 아이콘
- 짧은 명령 이름
- 쿨타임
- 현재 실행 중 표시

## 5. 프로토타입 입력 피드백

현재는 음성 UI를 표시하지 않는다.
숫자키 입력 결과를 같은 피드백 영역에 표시한다.

성공 예:

```text
[1] 추적
강아지가 흔적을 따라갑니다.
```

실패 예:

```text
[1] 추적 실패
유효한 흔적이 없습니다.
```

## 6. 향후 음성 피드백

음성 기능 통합 이후에만 활성화한다.

```text
들은 말: "저 골목 찾아봐"
인식 명령: 주변 수색
결과: 실행 중
```

낮은 신뢰도의 명령은 자동 실행하지 않는다.
음성 실패 시 바로 숫자키와 버튼 입력을 안내한다.

## 7. 상호작용

상호작용 가능한 대상 근처에서만 짧은 프롬프트를 표시한다.

예:

- `E 보물 줍기`
- `E 보물 내려놓기`
- `E 까마귀 상인에게 판매`
- `E 체포 시도`
- `R 물건 던지기`

동시에 여러 대상이 있을 때 우선 대상과 변경 방법을 명확히 표시한다.

## 8. 체포 UI

- 체포 진행도는 경찰과 도둑 모두에게 보인다.
- 시작, 중단, 완료 상태를 색상과 소리로 구분한다.
- 체포가 중단되면 이유를 길게 설명하지 않고 범위 이탈 또는 방해 아이콘을 표시한다.

## 9. 보물과 판매 UI

- 보물 등급은 형태와 아이콘으로도 구분한다.
- 보유 중인 보물은 HUD와 캐릭터 위 표시가 일치해야 한다.
- 까마귀 상인이 판매 불가 상태라면 이유를 표시한다.
- 판매 완료 후 증가 금액과 누적 금액을 짧게 강조한다.

## 10. 추격과 피격 피드백

- 추격 시작 시 과도한 경고창 대신 음악과 화면 가장자리 반응을 사용한다.
- 투척물에는 궤적과 바닥 그림자를 표시한다.
- 피격 순간의 화면 흔들림은 짧고 강도가 제한되어야 한다.
- 바나나 미끄러짐은 아이콘보다 캐릭터 동작과 사운드로 우선 전달한다.

## 11. 첫 경기 안내

세 문장 이내의 역할별 안내를 사용한다.

경찰:

```text
도둑이 보물을 팔지 못하게 막으세요.
숫자키로 강아지에게 추적과 경계를 명령하세요.
가까이 붙어 체포를 완료하면 승리합니다.
```

도둑:

```text
보물을 훔쳐 까마귀 상인에게 판매하세요.
숫자키로 고양이에게 정찰과 교란을 명령하세요.
4분 안에 목표 금액을 모으면 승리합니다.
```

목표 금액이 확정되기 전에는 숫자를 문구에 직접 넣지 않는다.

## 12. 결과 화면

- 승리 진영
- 승리 이유
- 남은 시간
- 최종 판매 금액
- 명령 사용 횟수
- 체포 및 추격 요약
- 역할을 바꿔 재경기
- 같은 역할로 재경기
- 메인 메뉴

## 13. 접근성과 해상도

- 키보드 입력과 화면 버튼을 함께 제공할 수 있는 구조를 유지한다.
- 텍스트 크기와 아이콘 대비를 작은 화면에서 확인한다.
- 16:9를 기준으로 하되 16:10과 창 모드에서 핵심 HUD가 잘리지 않아야 한다.
- 화면 흔들림 강도를 조절하거나 끌 수 있게 확장 가능한 구조로 둔다.
- 음성 기능은 유일한 조작 수단이 아니다.

## 14. 프로토타입 완료 기준

- 역할별 HUD가 구분된다.
- 숫자키 `1`~`4`의 상태가 보인다.
- 명령 성공과 실패 이유가 보인다.
- 체포 진행과 보물 판매 진행이 보인다.
- 4분 타이머와 결과 화면이 연결된다.
- 음성 기능이 없어도 모든 핵심 흐름을 완료할 수 있다.
