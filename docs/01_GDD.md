# 게임 디자인 문서

## 1. 게임 비전

멍경찰과 냥도둑은 말랑하고 허술한 캐릭터들이 작은 3D 마을에서 벌이는 우당탕 추격 코미디다.
정보 수집, 경로 선택, 동물 명령의 타이밍이 핵심이며 복잡한 전투와 높은 조작 난도는 지향하지 않는다.

## 2. 디자인 원칙

### 목표가 즉시 읽혀야 한다

- 경찰은 도둑을 잡고 보물을 지킨다.
- 도둑은 보물을 훔쳐 까마귀 상인에게 판매한다.
- 첫 화면에서 역할, 남은 시간, 현재 목표를 이해할 수 있어야 한다.

### 동물 명령이 실제 결과를 만들어야 한다

- 강아지의 추적은 도둑 탐색 시간을 줄여야 한다.
- 강아지의 경계는 도둑의 경로 선택을 바꿔야 한다.
- 고양이의 정찰은 도둑에게 새로운 정보를 제공해야 한다.
- 고양이의 교란은 경찰의 판단이나 이동을 흔들어야 한다.

### 명령 입력 방식과 게임 규칙을 분리한다

키보드, 버튼, 향후 음성 입력은 모두 동일한 명령 ID를 만든다.
음성을 사용할 수 없거나 인식에 실패해도 경기를 계속할 수 있어야 한다.

### 귀여움은 승패를 망치지 않는다

과장된 달리기와 대기 행동은 캐릭터를 우습게 보이게 할 수 있다.
핵심 명령을 무작위로 무시하거나 플레이어 입력을 지연시키는 방식은 사용하지 않는다.

### 한 경기는 짧고 재경기하고 싶어야 한다

경기는 4분이며 결과 화면에서 역할을 바꿔 빠르게 재경기할 수 있어야 한다.

## 3. 게임 기둥

### 두 역할을 동시에 운영하는 협동감

플레이어 캐릭터는 직접 움직이고 동물 파트너는 별도 명령을 수행한다.

### 비대칭 정보전

경찰은 흔적과 경계를 이용해 정보를 좁힌다.
도둑은 정찰과 교란으로 안전한 경로와 잘못된 정보를 만든다.

### 읽기 쉬운 추격

카메라는 경찰, 도둑, 동물 파트너, 투척물의 관계를 동시에 보여준다.

### 물리 코미디

바나나 미끄러짐, 물건 투척, 급정지, 모자와 가방의 후속 움직임으로 가볍고 우스운 충돌을 만든다.

## 4. 경찰

### 목표

도둑을 체포하거나, 4분 동안 도둑이 목표 판매 금액을 달성하지 못하게 한다.

### 주요 행동

- 순찰과 경로 차단
- 도난 알림 확인
- 도둑 추적
- 투척물로 도주 방해
- 체포 시도
- 강아지 명령

### 강점

- 강아지를 통한 안정적인 탐색
- 주요 통로와 판매 지점 차단
- 도둑을 직접 체포 가능

### 약점

- 모든 보물 구역을 동시에 지킬 수 없음
- 잘못된 정보에 반응하면 시간이 낭비됨
- 고양이의 교란과 우회 경로에 취약함

## 5. 도둑

### 목표

4분 안에 보물을 훔쳐 까마귀 상인에게 판매하고 목표 금액을 달성한다.

### 주요 행동

- 보물과 경찰 위치 파악
- 침투 경로 선택
- 보물 획득과 운반
- 환경 소품 투척과 도주 방해
- 까마귀 상인에게 판매
- 고양이 명령

### 강점

- 다양한 우회 경로
- 고양이를 통한 선행 정찰과 교란
- 목표와 진입 시점을 먼저 선택 가능

### 약점

- 보물 소지 중 이동 페널티
- 판매 지점까지 직접 운반해야 함
- 체포 완료 시 즉시 패배
- 한 번에 하나의 보물만 운반

## 6. 핵심 게임 루프

### 경찰 루프

순찰 → 정보 획득 → 강아지 명령 → 위치 추정 → 경로 차단 → 추격 → 체포

### 도둑 루프

정찰 → 보물 선택 → 경찰 확인 → 침투 → 획득 → 교란과 도주 → 까마귀 상인 판매

## 7. 동물 파트너

### 강아지

- `TRACK`: 유효한 도둑 흔적을 따라간다.
- `SEARCH`: 지정한 주변을 수색한다.
- `GUARD`: 지정 위치를 일정 시간 지킨다.
- `BARK`: 가까운 도둑을 압박하거나 위치를 드러낸다.

### 고양이

- `SCOUT`: 보물 또는 경찰 위치를 정찰한다.
- `DISTRACT`: 소리나 가짜 흔적으로 경찰을 교란한다.
- `STEAL`: 가까운 보물과 상호작용한다.
- `HIDE`: 보물이나 자신을 은신 지점에 숨긴다.

명령별 최종 효과와 쿨타임은 플레이테스트 후 확정한다.

## 8. 맵

MVP 맵은 작고 순환 가능하며 모든 주요 장소에 두 개 이상의 접근 경로가 있어야 한다.

필수 구역 후보:

- 경찰서
- 슈퍼마켓
- 서점
- 보석상
- 중앙 광장
- 까마귀 상인 출현 지점
- 골목
- 사다리와 제한된 지붕 경로
- 쓰레기통 또는 수풀 은신 지점

맵 조건:

- 경찰 시작 지점에서 모든 판매 후보 지점이 바로 보이지 않는다.
- 지붕은 완전한 안전지대가 아니다.
- 막다른 길에는 명확한 위험과 보상이 있다.
- 20초 이상 아무 정보도 얻지 못하는 구간을 줄인다.
- 건물은 카메라를 가릴 때 투명 처리할 수 있는 단위로 제작한다.

## 9. 보물과 까마귀 상인

보물은 일반, 고급, 희귀 등급을 가질 수 있다.
가격과 배치 수량은 아직 확정하지 않는다.

도둑은 한 번에 보물 하나만 운반한다.
보물 소지 중에는 이동 속도 감소와 소지 아이콘이 적용된다.

까마귀 상인은 도둑의 판매 NPC다.
출현 방식, 위치 변경 여부, 판매 소요 시간은 별도 플레이테스트 항목이다.
기존 암시장, 비밀 장터, 너구리 상인 설정은 사용하지 않는다.

## 10. 체포

체포는 접촉 즉시 완료되지 않는다.

1. 경찰이 도둑의 체포 범위에 들어간다.
2. 체포 입력 또는 자동 진행 조건을 만족한다.
3. 일정 시간 범위를 유지하면 체포가 완료된다.
4. 도둑이 범위를 벗어나거나 경찰이 방해받으면 진행이 중단된다.

초기 체포 시간 후보는 1.5초지만 플레이테스트 전 확정값이 아니다.

## 11. 투척과 방해

양 진영은 맵의 가벼운 물건을 주워 던질 수 있다.
투척은 피해량 중심의 전투가 아니라 짧은 기절, 이동 방해, 추격 경로 변경을 만든다.

초기 예시:

- 돌 또는 캔: 짧은 경직
- 바나나 껍질: 밟으면 미끄러짐
- 뼈다귀: 강아지의 추적을 잠시 흔듦

모든 투척물은 궤적, 그림자, 착탄 효과가 읽혀야 한다.
방해 시간과 쿨타임은 `docs/03_GAME_RULES.md`의 가설 값으로 관리한다.

## 12. 카메라

- 원근 투영 3D 카메라
- 지면을 약 50~55도로 내려다보는 각도
- 마을이 입체적으로 보이도록 수평 방향 35~45도 회전
- 초기 FOV 후보 38~45
- 추격 속도가 높아지면 8~12% 줌아웃
- 건물 가림 시 지붕과 벽 투명화
- 피격 시 짧은 흔들림과 확대, 0.1초 안팎의 히트 스톱

1인칭은 핵심 시점으로 사용하지 않는다.

## 13. 애니메이션

조작은 정확하게 유지하고 캐릭터의 몸만 과장되게 반응한다.

경찰:

- 팔을 옆으로 벌린 추격 달리기
- 짧은 다리의 빠른 스텝
- 모자와 눈알의 후속 흔들림

도둑:

- 앞으로 기울인 도주 자세
- 돈가방의 큰 좌우 흔들림
- 뒤를 보다가 휘청거리는 동작

동물:

- 강아지의 과도한 돌진과 미끄러운 급회전
- 고양이의 종종걸음과 발각 후 전력 질주

## 14. 정보 표현

경찰에게 제공:

- 강아지가 찾은 흔적
- 도난 발생 위치
- 짖기로 드러난 위치
- 까마귀 상인 거래 시작 알림

도둑에게 제공:

- 고양이가 확인한 보물
- 고양이가 확인한 경찰 또는 위험 구역
- 현재 보유 보물 가치
- 까마귀 상인 판매 가능 여부

## 15. 결과 화면

- 승리 진영
- 승리 이유
- 최종 판매 금액
- 남은 시간
- 사용한 동물 명령 횟수
- 추격과 체포 관련 간단한 통계
- 역할 교대 재경기
- 메인 메뉴

## 16. 미확정 항목

- 목표 판매 금액
- 보물 등급별 가격
- 체포 유지 시간
- 투척물 종류와 방해 시간
- 까마귀 상인 출현 방식
- 네트워크 패키지와 권한 주체
- 최종 배포 플랫폼
