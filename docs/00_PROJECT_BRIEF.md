# 프로젝트 브리프

## 프로젝트명

- 임시 제목: 멍경찰과 냥도둑
- 영문명: Paws & Loot

## 한 줄 소개

경찰은 강아지에게 추적과 경계를 명령하고, 도둑은 고양이에게 정찰과 교란을 명령해 4분 동안 보물을 지키거나 훔치는 1대1 음성 명령 비대칭 추격 게임.

## 발표용 30초 소개

멍경찰과 냥도둑은 경찰과 도둑이 각자의 AI 반려동물에게 직접 음성 명령을 내리며 대결하는 비대칭 추격 게임입니다. 경찰은 강아지의 후각을 이용해 도둑을 추적하고, 도둑은 고양이를 보내 보물을 찾거나 경찰의 시선을 돌립니다. 플레이어는 직접 움직이는 동시에 반려동물에게 명령해야 하므로, 혼자 조작하지만 둘이 협동하는 듯한 재미를 느낄 수 있습니다.

## 프로젝트 목표

공모전 제출용 MVP를 통해 다음 질문에 답한다.

> 플레이어가 자신의 캐릭터를 직접 움직이면서 별도의 동물 파트너에게 명령하는 플레이가 실제로 재미있는가?

## 핵심 경험

1. 캐릭터를 직접 조작하는 즉각적인 추격 액션
2. 동물 파트너와 역할을 나누는 협동감
3. 상대의 위치와 다음 경로를 예측하는 심리전
4. 투척, 미끄러짐, 과장된 달리기에서 발생하는 추격 코미디
5. 4분 안에 승패가 끝나는 짧고 반복 가능한 대전

## 핵심 차별점

일반적인 추격 게임은 플레이어 캐릭터 하나의 이동과 전투에 집중한다.
이 게임은 플레이어가 이동과 상호작용을 직접 수행하면서 동물 파트너에게 별도의 명령을 내려 두 역할을 동시에 운영하게 한다.

AI 동료는 자유 대화형 캐릭터가 아니라 제한된 명령을 안정적으로 수행하는 게임 에이전트다.
프로토타입에서는 숫자키 `1`~`4`로 명령 구조와 재미를 먼저 검증하고, 실제 음성 입력은 같은 명령 ID에 나중에 연결한다.

## 게임 형태

| 항목 | 내용 |
|---|---|
| 장르 | 캐주얼 전략 액션 / 비대칭 추격 |
| 인원 | 경찰 1명 대 도둑 1명 |
| 경기 시간 | 4분 |
| 시점 | 원근감 있는 3D 기울어진 탑다운 |
| 플랫폼 | 미정, PC 우선 검토 |
| 엔진 | Unity 6000.5.4f1 |
| 모델링 | Blender 원본 제작 후 FBX 반입 |

## 진영 목표

### 경찰

- 강아지의 추적과 경계를 이용한다.
- 도난을 방지하고 도둑의 이동 경로를 좁힌다.
- 도둑을 체포하거나 시간 종료까지 목표 판매 금액을 막는다.

### 도둑

- 고양이의 정찰과 교란을 이용한다.
- 경찰의 감시를 피해 보물을 획득한다.
- 보물을 까마귀 상인에게 판매해 목표 금액을 달성한다.

## 한 경기 흐름

1. 역할과 목표를 확인한다.
2. 5초 준비 후 4분 경기가 시작된다.
3. 도둑은 목표 보물과 도주 경로를 선택한다.
4. 경찰은 강아지를 활용해 의심 구역을 좁힌다.
5. 도둑은 고양이를 활용해 정찰하거나 경찰을 교란한다.
6. 보물 획득 후 추격과 방해가 발생한다.
7. 도둑은 까마귀 상인에게 판매를 시도한다.
8. 체포, 목표 금액 달성 또는 시간 종료로 승패가 결정된다.
9. 결과를 확인하고 역할 교대 재경기를 선택한다.

## 대상 이용자

- 짧고 직관적인 대전 게임을 좋아하는 이용자
- 귀여운 동물과 코믹한 캐릭터를 선호하는 이용자
- 복잡한 전투보다 상황 판단과 경로 선택을 좋아하는 이용자
- 명령형 AI가 실제 게임 규칙에 활용되는 사례를 보고 싶은 심사위원

## 현재 제작 원칙

- 최종 모델보다 그레이박스 핵심 루프를 먼저 완성한다.
- 실제 음성 인식보다 숫자키 명령을 먼저 완성한다.
- 본격 멀티플레이보다 로컬 규칙과 권한 경계를 먼저 검증한다.
- 기존 경찰 모델 한 체만 리깅과 애니메이션 파이프라인 검증에 사용한다.
- 기존 실험 프로토타입은 참고 자료이며 새 MVP의 구현 기준이 아니다.

## 성공 기준

- 첫 플레이어가 1분 안에 역할과 목표를 이해한다.
- 한 경기를 처음부터 결과 화면까지 완료할 수 있다.
- 두 진영 모두 동물 명령을 의미 있게 사용한다.
- 추격 중 상대와 동물 파트너의 상태가 한 화면에서 읽힌다.
- 플레이테스트에서 명령이 단순 장식이 아니라 승패 판단에 영향을 준다고 평가된다.

## 발표용 핵심 문장

> 플레이어가 AI를 구경하는 게임이 아니라, 직접 명령하고 역할을 분담하는 게임입니다.
