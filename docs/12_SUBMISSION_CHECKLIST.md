# 공모전 제출 체크리스트

## 1. 제출 요구사항 확인

- 공모전 최신 공고 확인
- 제출 마감 일시와 시간대 확인
- 허용 플랫폼과 파일 크기 확인
- AI 활용 문서 양식 확인
- 팀 역할 문서 양식 확인
- 외부 에셋과 오픈소스 규정 확인
- 개인정보와 음성 데이터 처리 요구 확인

## 2. 플레이 가능한 빌드

- 지정 링크 또는 파일로 실행 가능
- 로그인 없이 심사 가능
- 설치 또는 실행 절차가 README와 일치
- 새 PC 또는 새 브라우저 세션에서 실행
- 한 경기 완료 가능
- 경찰 승리 가능
- 도둑 승리 가능
- 결과 화면 정상
- 재시작 정상
- 치명적 콘솔 또는 플레이어 로그 오류 없음
- 마이크 거부 시 대체 입력으로 진행 가능

## 3. 핵심 게임 장면

- 경찰 이동과 강아지 명령
- 도둑 이동과 고양이 명령
- 추적 또는 경계
- 정찰 또는 교란
- 보물 획득과 운반
- 너구리 상인 판매
- 체포
- 투척 또는 코믹 방해
- 승리와 패배

## 4. 음성과 AI

음성 기능을 제출 범위에 포함할 때만 확인한다.

- 마이크 권한 요청
- 음성 명령 성공
- 불확실한 명령 거부
- 키보드와 버튼 대체 입력
- 서비스 실패 후 경기 지속
- 음성 데이터 저장 여부와 고지
- 자유 대화 AI가 아니라 제한 명령 에이전트임을 설명

## 5. 소스 코드

- 저장소 접근 권한 확인
- 기본 브랜치와 제출 커밋 고정
- README 최신
- 실행 방법 정확
- `docs/13_CURRENT_STATE.md` 최신
- 비밀 키와 토큰 제거
- 로컬 경로와 사용자 이름 제거
- `Library`, `Temp`, `Logs`, `UserSettings` 제외
- 자동 생성 IDE 파일 제외
- 테스트와 문서 포함
- 외부 에셋 라이선스 기록

## 6. 플레이 영상

- 공모전 요구 길이 준수
- 게임 제목 표시
- 역할과 목표가 5초 안에 보임
- 경찰과 도둑 플레이 모두 포함
- 강아지와 고양이 명령 장면
- 추격과 코믹 애니메이션
- 보물과 너구리 상인 판매
- 체포 또는 승리 장면
- 필요한 자막과 음성 설명
- 실제 빌드 화면만 사용

## 7. 게임 소개 문서

- 제목: 멍경찰과 냥도둑 / Pawlice and Purrglar
- 한 줄 소개
- 30초 소개
- 장르와 플랫폼
- 대상 이용자
- 핵심 게임 루프
- 진영별 역할
- 승리 조건
- 동물 명령 차별점
- 카메라와 아트 방향
- 대표 이미지와 스크린샷
- 실행 방법
- 팀 정보

## 8. AI 활용 기술 문서

- 사용한 AI 도구와 모델
- 개발 단계별 사용 목적
- 대표 프롬프트
- 생성 결과
- 사람이 수정하고 검증한 내용
- 실패와 폐기 사례
- 최종 반영 파일
- 저작권과 라이선스 검토
- 음성 데이터와 개인정보 고려
- AI가 게임 규칙에 기여하는 방식

## 9. 팀 역할 기술서

- 팀원명
- 담당 역할
- 담당 기능
- 구체적 산출물
- 협업 내용

- 검토와 검증 책임
- 최종 기여도

## 10. 에셋과 라이선스

- 모델
- 텍스처
- 폰트
- 음원
- 효과음
