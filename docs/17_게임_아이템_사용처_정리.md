# 건물별 아이템 사용처 및 기능 구현 문서

> 기능 구현을 위한 건물별 아이템 정리 문서입니다.  
> 현재 문서는 **Jewelry Store(보석 상점)**, **Book Store(서점)**, **Market(마트)**, **Random Box(랜덤 박스)**, **Cat Interact(고양이 상호작용)**, **Expression Icon(동물 감정 상태 아이콘)**, **Dog Interact(강아지 상호작용)** 아이템을 기준으로 작성한 초안입니다.

---

## 공통 아이템 처리 규칙

| 항목 | 기본 규칙 |
|---|---|
| 획득 주체 | 기본적으로 도둑 플레이어. 단, 경찰 전용 구매 아이템처럼 별도 규칙이 있는 경우 해당 항목을 우선 적용 |
| 기본 상호작용 | 아이템 근처에서 `E` 키를 눌러 획득 |
| 보관 위치 | 획득 주체의 가방 또는 인벤토리. 사용형 아이템은 필요에 따라 퀵슬롯에 등록 |
| 주요 사용처 | 암시장에서 판매하여 점수 또는 재화를 획득 |
| 분실 조건 | 체포, 아이템 투척, 가방 드롭 등 세부 규칙에 따라 처리 |
| 경찰 상호작용 | 바닥에 떨어진 아이템 확인, 압수 또는 도둑 추적 단서로 활용 가능 |
| 구현 공통 데이터 | 아이템 ID, 표시 이름, 프리팹, 아이콘, 판매가, 무게, 희귀도, 획득 가능 여부 |

## 1.2 기능 구현 분류

| 기능 그룹 | 포함 아이템 | 구현 방식 |
|---|---|---|
| 일반 루팅 아이템 | 황금 왕관, 황금 손목시계, 진주 목걸이, 다이아몬드 반지, 에메랄드 보석, 블루 보석, 레드 보석, 금메달, 금괴, 금 체인 팔찌 | 월드 프리팹에 상호작용 컴포넌트를 부착하고 획득 시 인벤토리에 아이템 데이터 추가 |
| 보물상자 내부 핵심 보상 | 보석 전시 돔 | 월드에 직접 노출하지 않고 보석 상점 중앙의 보물상자 내부 보상으로 연결. 상자 개봉 완료 시 인벤토리에 추가 |
| 열쇠 잠금 오브젝트 | 보물상자 | 보석 상점 중앙에 크게 배치. 플레이어가 열쇠를 보유한 경우에만 개봉 가능하며, 개봉 시 열쇠 1개를 소모하고 보석 전시 돔을 지급 |
| 소모형 열쇠 처리 | 열쇠 | 보물상자 개봉 시 인벤토리에서 1개 차감. 사용하지 않은 열쇠는 매우 낮은 가격으로 판매 가능 |
| 판매 처리 | 모든 획득 가능 귀중품 및 미사용 열쇠 | 암시장 NPC 또는 판매 지점에서 아이템 제거 후 판매가만큼 점수 또는 재화 지급 |
| 드롭 처리 | 인벤토리에 들어간 모든 아이템 | 가방에서 버리거나 체포 시 월드 드롭 프리팹으로 재생성 |

## 1.3 핵심 상호작용 흐름

```text
열쇠 획득
→ 보석 상점 중앙의 보물상자에 접근
→ 열쇠 보유 여부 확인
→ 보물상자 개봉과 동시에 열쇠 1개 소모
→ 내부의 보석 전시 돔(아주 비싼 반지) 획득
```

| 판매가 및 무게 | 게임 밸런스 문서에서 별도로 수치 확정 | 미정 |
| 세트 보너스 | 기본 구현에서는 적용하지 않고, 밸런스상 필요할 때만 후순위 기능으로 추가 | 기본 미적용 |

```text
모든 맵의 랜덤 스폰 지점에서 붉은 구체 생성
```

## 5.4 고양이 AI 상호작용 흐름

```text
경찰이 마트에서 고양이 상호작용 아이템 구매
→ 경찰 인벤토리 또는 퀵슬롯에 아이템 등록
→ 지붕 위 또는 월드에서 행동 중인 고양이 확인
→ 아이템 배치·투척 또는 레이저 조준
→ 고양이가 유인 범위와 경로 도달 가능 여부 확인
→ 현재 행동과 유인 아이템의 우선순위 비교
→ 고양이의 관심 대상을 아이템 또는 레이저 지점으로 변경
→ 고양이가 해당 위치로 이동하거나 일정 시간 상호작용
→ 지속 시간 종료 또는 아이템 소모 후 기존 AI 행동으로 복귀
```

## 6.4 상태 전환 예시

### 명령 이해 관련

```text
플레이어가 동물에게 음성 명령 전달
→ 명령 파싱 결과 확인
→ 명확히 이해하면 전구 아이콘 표시
→ 애매하거나 혼동되면 물음표 아이콘 표시
→ 해당 결과에 따라 AI가 명령 수행 또는 오해 행동 실행
```

### 방해 / 독성 관련

```text
동물이 방해 아이템 또는 toxic bottle 효과 범위에 들어감
→ 상태 판정
→ 방해 아이템이면 어지러움 아이콘 표시
→ 독성 병이면 현재 수행 중인 명령을 즉시 취소하고 혐오 가스 아이콘 표시
→ 일정 시간 동안 효과 지점과 사용자를 피해 도망
→ 효과 종료 후 강아지는 경찰 주변으로, 고양이는 도둑 주변으로 이동
→ 아이콘 제거 후 각 동물의 기본 동행 상태로 복귀
```

### 추적 / 발견 관련

```text
강아지가 도둑 또는 고양이의 흔적 발견
→ 강아지 코 아이콘 표시
→ 앞쪽에 발자국(paws) 경로 일부 생성
→ 경로를 따라 추적 행동 수행
→ 은신처 내부 목표를 확실히 탐지하면 빨간 깃발 아이콘으로 전환
```

### 호감 / 상호작용 관련

```text
간식 사용, 선호 아이템 사용 또는 G 키 쓰다듬기 성공
→ 하트 아이콘 표시
→ 동물이 해당 플레이어 또는 위치에 긍정 반응

```

## 7.4 Toxic Bottle 처리 흐름

```text
강아지 또는 고양이가 명령 수행 중
→ toxic bottle 투척물에 맞거나 효과 범위 진입
→ 현재 명령 즉시 취소
→ hate gas 아이콘 표시
→ 독성 지점 반대 방향으로 일정 시간 도주
→ 효과 시간 종료
→ 강아지는 경찰 주변으로 복귀
→ 고양이는 도둑 주변으로 복귀
→ 기본 동행 또는 대기 상태로 전환
```

## 8.4 사용 흐름 예시

### 일반 스턴 투척 아이템

```text
도둑이 돌 / 초록병 / 캔 획득
→ 퀵슬롯 등록
→ 사람 캐릭터를 향해 조준 후 투척
→ 명중 판정 성공
→ 대상이 갑자기 쓰러짐
→ 일정 시간 기절 상태 유지
→ 상태 종료 후 다시 이동 가능
```

### 냉동 문어

```text
도둑이 매우 희귀한 냉동 문어 획득
→ 퀵슬롯 등록
→ 사람 캐릭터를 향해 투척
→ 명중 시 대상 일시 정지
→ 동시에 먹물 효과로 시야 차단
→ 일정 시간 후 상태 해제
```

### 바나나

```text
도둑이 바나나 획득
→ 퀵슬롯 등록
→ 대상에게 던지거나 바닥에 투척
→ 명중 또는 밟기 판정 성공
→ 대상이 미끄덩하며 공중제비를 돌고 넘어짐
→ 짧은 경직 후 다시 이동 가능
```

### 열쇠

```text
도둑이 드문 확률로 등장한 열쇠 획득
→ 인벤토리에 보관
→ 보석 상점 중앙의 큰 treasure chest 접근
→ 열쇠 보유 여부 확인
→ 상자 개봉 및 열쇠 1개 소모
→ 내부 보상 획득
```

| 설치형 소모품 | 경찰 경광등 알람, 폴리스 테이프, 공사장 바리케이드 | 설치 성공 시 인벤토리 수량 1개 차감하고 월드 설치 프리팹 생성 |
| 최초 경찰 투척 오브젝트 | 교통 콘 | 인벤토리 또는 경찰 장비에서 최초 생성·투척 권한은 경찰에게만 부여 |
| 양 팀 물리 상호작용 | 교통 콘 | 월드에 떨어진 뒤에는 경찰과 도둑 모두 발차기 충돌로 다시 이동시킬 수 있게 처리 |
| 길목 통제 | 폴리스 테이프, 공사장 바리케이드, 교통 콘 | 출입구·골목·계단 등 이동 경로에 충돌체 또는 감속·방해 판정을 생성 |
| 탐색 / 알림 | 손전등, 경찰 경광등 알람, 무전기, 경찰 호루라기 | 시야 확보, 경보, 팀 정보 공유, AI 또는 동료 호출 이벤트와 연동 |

## 9.4 교통 콘 특수 처리 흐름

```text
경찰이 교통 콘을 장착
→ 경찰만 최초 투척 가능
→ 교통 콘이 월드에 떨어져 물리 오브젝트로 전환
→ 이후 경찰 또는 도둑이 교통 콘에 발차기 판정 발생
→ 발차기 방향과 힘에 따라 교통 콘이 다시 날아감
→ 충돌하거나 멈출 때까지 물리 이동
→ 월드에 남아 반복적으로 다시 찰 수 있음
```

### 권한 구분

| 상태 | 경찰 | 도둑 |
|---|---:|---:|
| 인벤토리에서 꺼내 최초 투척 | 가능 | 불가능 |
| 월드에 떨어진 콘을 발로 차기 | 가능 | 가능 |
| 떨어진 콘을 다시 인벤토리에 회수 | 추후 결정 | 추후 결정 |
| 콘을 이용해 상대에게 물리 충돌 유발 | 가능 | 가능 |

## 9.5 설치형 소모품 처리 흐름

```text
경찰이 설치형 아이템 선택
→ 설치 미리보기 표시
→ 설치 가능 지면 및 거리 확인
→ 설치 확정
→ 인벤토리 수량 1개 차감
→ 경찰 경광등 알람 / 폴리스 테이프 / 공사장 바리케이드 프리팹 생성
→ 지속 시간 또는 파괴 조건 충족 시 월드에서 제거
```

## 9.6 Police Items 추가 데이터 필드 권장안

| 필드 | 사용 대상 | 설명 |
|---|---|---|
| `PoliceOnly` | 전체 | 경찰만 인벤토리에서 사용할 수 있는지 여부 |
| `ConsumeOnUse` | 전체 | 사용 또는 설치 시 수량을 소모하는지 여부 |
| `Reusable` | 비소모형 장비 | 사용 후에도 계속 보유하는지 여부 |
| `PlacementType` | 설치형 3종 | 단일 지점, 선형 설치, 넓은 충돌체 등 설치 방식 |
| `PlacementPreviewPrefab` | 설치형 3종 | 설치 전 위치와 크기를 보여주는 미리보기 프리팹 |
| `PlacementLifetime` | 설치형 3종 | 설치물이 유지되는 시간 |
| `CanBeDestroyed` | 설치형 3종 | 다른 캐릭터가 파괴할 수 있는지 여부 |
| `Durability` | 공사장 바리케이드 등 | 설치물의 내구도 |
| `InitialThrowOwner` | 교통 콘 | 최초 투척 권한을 가진 팀. 현재는 경찰 |
| `CanBeKickedByPolice` | 교통 콘 | 경찰의 발차기 상호작용 허용 여부 |
| `CanBeKickedByThief` | 교통 콘 | 도둑의 발차기 상호작용 허용 여부 |
| `KickForce` | 교통 콘 | 발차기로 적용되는 물리 힘 |
| `WorldPersistence` | 교통 콘 | 월드에 얼마나 오래 남아 있는지 |
| `StunDuration` | 테이저건 | 명중 대상의 스턴 지속 시간 |
| `ArrestDuration` | 수갑 | 체포 상호작용에 필요한 시간 |
| `LightRange` | 손전등, 경광등 알람 | 빛이 영향을 주는 거리 |
| `AlertRadius` | 경광등 알람, 호루라기 | 알림 또는 경보가 전달되는 범위 |
| `Cooldown` | 비소모형 장비 | 반복 사용 사이의 재사용 대기시간 |
