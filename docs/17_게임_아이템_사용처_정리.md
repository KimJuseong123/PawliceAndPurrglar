# 경찰과 도둑 게임 아이템 사용처 정리

> 슈퍼마켓, 서점, 주얼리샵에 배치되는 판매용 아이템과 상호작용 아이템의 역할을 정리한 문서입니다.  
> 판매용 아이템은 도둑이 훔쳐 암시장에 판매하는 전리품이며, 상호작용 아이템은 경찰·도둑·동물 AI와 추격 및 방해에 활용합니다.

---

## 1. 공통 분류 기준

### 아이템 타입

| 타입 | 설명 |
|---|---|
| `SELLABLE` | 도둑이 훔쳐 암시장에 판매할 수 있는 전리품 |
| `INTERACTIVE` | 던지기, 설치, 유인, 방해 등에 사용하는 아이템 |
| `CONTAINER` | 다른 아이템을 보관하거나 랜덤 전리품을 제공하는 오브젝트 |
| `SECURITY` | 진열장, 경보 장치처럼 절도 난도를 높이는 오브젝트 |
| `ENVIRONMENT` | 도로, 가로등, 나무처럼 맵을 구성하는 환경 오브젝트 |

### 휴대 방식

| 휴대 방식 | 처리 방식 |
|---|---|
| `POCKET` | 소형 아이템. 이동속도 감소 없음 |
| `ONE_HAND` | 한 손 운반. 다른 손 상호작용 일부 제한 |
| `TWO_HAND` | 양손 운반. 공격·투척·동물 명령 일부 제한 |
| `BULKY` | 크고 무거움. 이동속도 감소 및 위치 노출 증가 |

# 4. 주얼리샵

## 장소 콘셉트

- 가장 높은 가치의 아이템이 모여 있지만 진열장과 경보 때문에 털기 어려운 공간이다.
- 아이템을 꺼내기 전에 유리 진열장을 열거나 부수는 과정이 필요하다.
- 대표 목표물인 대왕 반지를 획득하면 사이렌이 울리고 일정 시간 경찰 이동속도가 증가한다.
- 반지, 보석, 금괴처럼 탑뷰에서도 실루엣이 분명한 오브젝트를 중심으로 구성한다.

## 대왕 반지 경보 이벤트

1. 도둑이 대형 유리 진열장을 연다.
2. 반지를 진열대에서 분리하는 순간 사이렌이 울린다.
3. 경찰에게 주얼리샵 위치가 표시된다.
4. 일정 시간 경찰의 이동속도가 증가한다.
5. 반지를 든 도둑은 이동속도가 감소하거나 미니맵에 주기적으로 노출된다.
6. 반지를 암시장까지 운반하면 최고 등급 보상을 획득한다.

## 시각적 표현 규칙

- 반지는 일반 반지보다 크게 만들고 전용 케이스 안에 단독으로 배치한다.
- 목걸이는 진열판과 하나의 세트처럼 보이게 배치한다.
- 루비, 사파이어, 에메랄드는 현실보다 약 1.5~2배 크게 표현한다.
- 금괴와 왕관은 멀리서도 종류를 알 수 있도록 실루엣을 단순하게 유지한다.
- 진열장 유리는 실제보다 크고 만화적으로 표현해 내부 아이템이 가려지지 않게 한다.
- 유리와 내부 아이템은 별도 오브젝트로 분리해 파손 및 획득 애니메이션을 구현한다.

# 7. 구현 우선순위

## 1차 구현

- 슈퍼마켓: 사과, 고급 양주병, 계산대 돈통, 한우 선물세트
- 서점: 일반 책, 노트북, 만년필, 캐릭터 피규어
- 주얼리샵: 반지, 손목시계, 금괴, 루비, 진열장
- 상호작용: 참치캔, 바나나, 고무닭, 냉동 문어, 폭죽

## 2차 구현

- 슈퍼마켓의 나머지 판매용 아이템
- 서점의 고서, 마법책, 지구본, 책갈피
- 주얼리샵의 목걸이, 왕관, 보석함, 금화
- 매장별 경보와 경찰 강화 이벤트

## 3차 구현

- 세트 수집 보너스
- 랜덤 내용물 선물상자 및 보석함
- 아이템 파손, 깨짐, 떨어뜨림
- 동물 AI별 유인 우선순위
- 매장별 희귀 아이템 랜덤 등장
